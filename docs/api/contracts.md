# Contratos

O contrato inicial é publicado pela API em `/openapi.json`. A rota `GET /api/v1/health` responde com HTTP 200 e `{"status":"ok"}` quando a API está acessível. Esse retorno informa apenas a disponibilidade do processo HTTP.

Este diretório é reservado para artefatos compartilhados ou gerados a partir do OpenAPI quando houver consumidores que precisem deles.
